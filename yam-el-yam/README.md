## טעינה ל-Mapeak

1. קודם מוחקים גרסאות ישנות של המסלול, אחרת המסלולים מתחברים.
2. טלפון: פותחים את הקובץ ← שיתוף ← Mapeak.
   מחשב: mapeak.com ← Private Routes ← אייקון התיקייה, או גוררים את הקובץ למפה.
3. טוענים רק את `color-segments`. לא צריך לטעון גם את `v3`.
4. מורידים את המפה לשימוש בלי אינטרנט.

## בנייה מחדש

```bash
pip install matplotlib
python3 -I yam-el-yam/build_gpx.py --cache /tmp/yam-cache --out yam-el-yam
```

הסקריפט צריך גישה ל-`api.openstreetmap.org` (המסלול) ול-`israelhiking.osm.org.il` (הגבהים). בתיקיית ה-cache נשמרים המסלול שהורד וגם הגבהים, ובהרצה הבאה לא מורידים אותם שוב. כדי לשנות שעות, נקודות או גבולות מקטעים, עורכים את הקבועים בראש הסקריפט: `CUT_KM`, `SEGMENTS`, `REFILL`, `SCHEDULE`.

הדרך: OSM relation 2860967 ("מסע מים אל ים"). בונים גרף מכל ה-ways שלו ומחשבים את המסלול הקצר ביותר מ-node 13289769538 (יד לי"ד) ל-node 10254819616 (הכנרת). הגבהים מגיעים מ-Israel Hiking Map, ב-200 נקודות לכל בקשה. אחר כך חותכים את המסלול בק"מ 0, 8.0, 19.9, 29.6, 38.9, 43.2, 49.8, 62.1 ובסוף. כל מקטע נשמר כ-`<trk>` עם `<extensions><Color>/<Opacity>/<Weight>`, וזה מה ש-Mapeak קורא כצבע.
