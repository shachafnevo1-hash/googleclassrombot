# פוסטרים למעמד ביקורות NFC

שישה פוסטרים למוצר, כל אחד בסגנון אחר. כולם נבנו בקוד (HTML / Canvas / SVG) ומרונדרים ל־PNG ברזולוציה 2160×2700 (יחס 4:5, מתאים לפוסט באינסטגרם).

| קובץ | סגנון | מה קורה בקוד |
|---|---|---|
| `posters/01-8bitgame.html` | משחק 8-ביט | כל הסצנה מצוירת פיקסל־פיקסל על רשת של 180×225; תמונת המוצר מוקטנת ומומרת לפלטה מוגבלת; הכותרת עוברת רסטריזציה לפיקסלים |
| `posters/02-typographyposter.html` | פוסטר טיפוגרפי | ה־TAP הענק מותאם לרוחב בדיוק לפי מדידה; המוצר "נכנס" בין האותיות (מאחורי ה־T ולפני ה־A); תג טקסט מעגלי ב־SVG |
| `posters/03-minimalposter.html` | מינימליסטי | שמש שוקעת מאחורי קו האופק; צל מגע וצל מוטל שנבנים מהצללית של המוצר |
| `posters/04-bauhaus.html` | באוהאוס | השילוש של קנדינסקי: עיגול כחול, משולש צהוב, ריבוע אדום; "1" ענק כמשחק מילים על "Tap אחד" |
| `posters/05-popart.html` | פופ־ארט | ארבעה הדפסי משי בסגנון וורהול: סיווג צבעים, נקודות הלפטון לפי ההצללה האמיתית בתמונה, קווי דיו (Sobel) והדפסה מוזזת |
| `posters/06-y2k.html` | Y2K | טקסט כרום עם תאורה ספקולרית ב־SVG, טבעת מסלול שעוברת מלפני המוצר ומאחוריו, חלון review.exe וכפתור Aqua |

## 07: תמונת ה־Hero (Y2K בתלת־ממד)

`posters/07-hero.html` היא סצנה תלת־ממדית אמיתית שמרונדרת ב־WebGL2, בשיטות של ray marching ו־path tracing, בתוך shader שנכתב במיוחד לפוסטר:

- **הכיתוב TAP! בכרום תלת־ממדי:** הטקסט הופך לשדה מרחק (Euclidean distance transform) ואז "נמתח" לעומק עם שיפוע מעוגל. הדגימה בטקסטורה היא ביקוביק B-spline, כדי שהשיפועים יהיו חלקים.
- **חומרים:** כרום עם השתקפות "אופק" רטרו, זהב, בועות סבון עם התאבכות שכבה דקה (thin-film), פודיום הולוגרפי ורצפה מבריקה.
- **המוצר האמיתי:** התמונה עומדת בסצנה כמשטח עם שקיפות. לכן היא משתקפת בכרום ובפודיום ומטילה צל. תחתית המעמד "מיושרת" לכל עמודה בנפרד, כך שהמעמד יושב על הפודיום בדיוק.
- **רינדור:** החלקת קצוות (anti-aliasing), צללים רכים ועומק שדה (depth of field), מצטברים על פני 40 דגימות לכל פיקסל.
- **עיבוד אחרי הרינדור:** bloom (פירמידה של 13 tap), נצנוצי כוכב בשיטת Kawase, מיפוי טונים Khronos PBR Neutral (שומר על צבעי המוצר), סטייה כרומטית קלה וגרעין.

```bash
python3 tools/prep_hero.py                                     # טקסטורת מוצר מוגדלת
QUERY="spp=4&scale=0.5" SUFFIX="-preview" TIMEOUT=1200000 \
  NODE_PATH=$(npm root -g) node render.cjs 07                  # תצוגה מקדימה מהירה
QUERY="spp=40" TIMEOUT=7000000 NODE_PATH=$(npm root -g) node render.cjs 07   # רינדור סופי
```

## רינדור מחדש

```bash
pip install pillow numpy scipy fonttools
python3 tools/cutout.py        # חיתוך המוצר מהרקע השחור -> assets/product-cutout.png
python3 tools/fetch_fonts.py   # הורדת הגופנים (כבר נמצאים ב-assets/fonts)
NODE_PATH=$(npm root -g) node render.cjs          # כל הפוסטרים
NODE_PATH=$(npm root -g) node render.cjs 05       # רק פוסטר אחד
```

כדי להחליף מוצר, שמים תמונה חדשה על רקע שחור ב־`assets/product-original.png` ומריצים שוב את שלושת השלבים.
